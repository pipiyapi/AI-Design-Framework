# AI Design Data rules

This repository contains user knowledge and evidence only. Framework code lives in the sibling/parent `AI-Design-Framework` repository.

- Keep raw tutorial evidence in `_evidence/`; normal project retrieval uses reviewed Workflow, Playbook, Pattern, Recipe, Principle, and Personal DNA layers.
- Raw recordings and downloaded source videos are temporary intake material only. Keep them in the ignored `.design-memory/intake-media/` cache, never in Git. Formal knowledge retains source links, compact transcripts, selected keyframes, and distilled methods.
- Keep new References and Workflows in `00-Inbox` until the user reviews them.
- Never copy long source prompts into published knowledge; retain distilled constraints and keep source text in evidence.
- Never store API keys, cookies, tokens, passwords, or Jimeng session material here.
- Image generation defaults to Codex Image Generation. Each Jimeng/Seedance video submission requires one explicit approval for one output; retries require approval again.
- Do not add Framework scripts, review UI, templates, tests, or generated `skill-dist` content to this repository.
