# AI Design Data

这是一份 AI Design Framework 兼容的个人知识数据仓库。它只保存知识、证据、媒体、项目反馈、索引与 Obsidian 配置，不包含采集脚本、审核页或 Skill 构建代码。

将本仓库放在 `AI-Design-Framework/data` 后，从 Framework 根目录运行所有命令。Obsidian 直接打开本仓库目录。

原始录像只在第一次分析时作为本地临时参考，放在 Git 忽略的 `.design-memory/intake-media/`。正式知识库仅保存来源链接、少量关键帧、转录摘要和提炼结果，不保存 MOV / MP4 / WEBM / MKV 文件。
