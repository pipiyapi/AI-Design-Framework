# AI Design Data

这是一份 AI Design Framework 兼容的个人知识数据仓库。它只保存知识、证据、媒体、项目反馈、索引与 Obsidian 配置，不包含采集脚本、审核页或 Skill 构建代码。

将本仓库放在 `AI-Design-Framework/data` 后，从 Framework 根目录运行所有命令。Obsidian 直接打开本仓库目录。

小红书、抖音和 B站教程直接写入 `07-Workflows`。每条笔记只有两部分：尽可能忠实的“原帖实现信息”，以及带检查点和失败回退的“Workflow SOP”；不使用 Inbox、Playbook 或 Recipe 晋升。

原始录像只在第一次分析时作为本地临时参考，放在 Git 忽略的 `.design-memory/intake-media/`。正式知识库保存来源链接、3–6 张关键帧和提炼结果；必要时允许保存 3–8 秒、最大 5 MB 的轻量效果预览，优先 WebM/MP4 或动态 WebP。
